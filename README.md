# Сервис учета ошибок программного продукта

Консольное приложение для регистрации, поиска и обработки ошибок, найденных
при тестировании или эксплуатации программного продукта.

## Возможности

- регистрация ошибки с заголовком, описанием, серьезностью и статусом;
- связь ошибки с пользователем, зарегистрировавшим ее;
- назначение разработчика, ответственного за исправление;
- справочник статусов обработки ошибки;
- автоматическое определение приоритета;
- просмотр ошибок с сортировкой по приоритету;
- поиск по заголовку и описанию;
- фильтрация по статусу и серьезности;
- изменение статуса и удаление ошибки;
- сохранение данных между запусками в JSON-файле.

## Структура проекта

- `main.py` - точка запуска и консольное меню;
- `errors.py` - функции обработки ошибок и коллекций;
- `entities.py` - типизированные сущности пользователя, разработчика и статуса;
- `storage.py` - загрузка и сохранение JSON;
- `utils.py` - безопасный ввод чисел;
- `data/errors.json` - данные зарегистрированных ошибок;
- `data/users.json` - пользователи, зарегистрировавшие ошибки;
- `data/developers.json` - разработчики, ответственные за исправление;
- `data/statuses.json` - справочник статусов;
- `test_main.py` - исходные тесты базовых функций;
- `tests/test_errors.py` - тесты функций учета ошибок.

## Запуск

```text
pip install -r requirements.txt
python main.py
```

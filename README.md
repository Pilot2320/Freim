# Сервис учета ошибок программного продукта

Консольное приложение для регистрации, поиска и обработки ошибок программного продукта. Версия ПР3 продолжает проект ПР2 и переводит основные сущности на объектную модель Python.

## Возможности

- регистрация ошибки с заголовком, описанием и серьезностью;
- связь ошибки с пользователем и ответственным разработчиком;
- автоматическое определение приоритета;
- просмотр, поиск и сортировка ошибок;
- фильтрация по статусу и серьезности;
- изменение статуса и удаление ошибки;
- загрузка объектов из JSON при запуске;
- сохранение объектов в JSON между запусками.

## Объектная модель

- `Error` - ошибка с атрибутами `id`, `title`, `description`, `severity`, `priority`, `status`, `user`, `developer`. Методы `__str__()`, `from_data()` и `to_data()`.
- `User` - пользователь, зарегистрировавший ошибку. Атрибуты `id`, `name`, `email`.
- `Developer` - разработчик, ответственный за исправление. Атрибуты `id`, `name`, `specialization`.
- `Status` - объект статуса обработки ошибки с атрибутами `id` и `name`.

Класс `Error` хранит ссылки на объекты `User`, `Developer` и `Status`. В JSON сохраняются только идентификаторы связанных объектов. При загрузке `storage.py` восстанавливает связи между объектами.

## Структура проекта

```text
models/
├── __init__.py
├── errors.py
├── users.py
├── developers.py
└── statuses.py

data/
├── errors.json
├── users.json
├── developers.json
└── statuses.json

tests/
├── test_errors.py
└── test_models.py
```

- `main.py` - консольное меню и пользовательские сценарии;
- `errors.py` - функции обработки коллекции объектов `Error`;
- `models/` - классы предметной области;
- `storage.py` - преобразование JSON в объекты и объектов в JSON;
- `utils.py` - безопасный ввод числовых значений;
- `tests/` - автоматизированные тесты объектной модели.

## Запуск

```text
pip install -r requirements.txt
python main.py
```

При добавлении ошибки серьезность и статус выбираются по числовому ID. Пользователь и разработчик выбираются по ID из JSON-справочников.

## Тестирование

```text
pytest -v
```

Тесты проверяют создание объектов, строковое представление, функции работы с ошибками, связи между объектами и JSON round trip. В текущей версии проходят 10 тестов.

### Пункт 9. Собственный менеджер и методы QuerySet (ErrorQuerySet, ErrorManager)
* **Показатель**: Продемонстрируйте работу собственного менеджера и методов QuerySet.
* **Где показать в коде**: `bugtracker/models.py`, строки 85–122:
  ```python
  class ErrorQuerySet(models.QuerySet):
      def active(self):
          return self.exclude(status__name__in=["Закрыта", "Исправлена"])

      def critical(self):
          return self.filter(severity=Severity.CRITICAL)

      def high_priority(self):
          return self.filter(priority=Priority.HIGH)

      def by_status(self, status_name):
          return self.filter(status__name=status_name)

  class ErrorManager(models.Manager.from_queryset(ErrorQuerySet)):
      pass
  ```
* **Команда в Django Shell**:
  ```python
  from bugtracker.models import Error
  print("Активные ошибки:", Error.objects.active().count())
  print("Критические ошибки:", Error.objects.critical().count())
  print("Высокий приоритет:", Error.objects.high_priority().count())
  print("Новые ошибки:", Error.objects.by_status("Новая").count())
  ```
* **Что сказать преподавателю**:
  - `models.Manager.from_queryset(ErrorQuerySet)` автоматически проксирует методы кастомного QuerySet в менеджер `objects`, обеспечивая единообразный интерфейс вызовов как от модели (`Error.objects.active()`), так и по цепочке методов (`Error.objects.active().critical()`).

  ```python
  from django.db import connection, reset_queries
  from bugtracker.models import Error
  import django
  django.db.connections['default'].force_debug_cursor = True

  reset_queries()
  # Без оптимизации:
  errors = list(Error.objects.all())
  for e in errors:
      _ = e.developer.name
  print("Запросов без select_related:", len(connection.queries))

  reset_queries()
  # С оптимизацией select_related:
  errors_opt = list(Error.objects.select_related("developer", "status", "user"))
  for e in errors_opt:
      _ = e.developer.name
  print("Запросов с select_related:", len(connection.queries))
  ```
* **Что сказать преподавателю**:
  - При `select_related` выполняется ровно 1 запрос вместо 1 + N.

  ```python
  @admin.display(description="Количество ошибок", ordering="_errors_count")
  def errors_count(self, obj):
      return getattr(obj, "_errors_count", obj.errors.count())
  ```
* **Что сказать преподавателю**:
  - В списке административной панели количество связанных ошибок вычисляется одним запросом через `annotate(Count('errors'))`, а не отдельным запросом в цикле для каждого разработчика.
